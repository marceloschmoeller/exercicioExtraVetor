# Exercício — Inversão de Vetor

## Descrição

O programa solicita ao usuário cinco números inteiros, armazena-os em um vetor e inverte a ordem dos elementos, exibindo os valores na ordem inversa.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Funcionamento

1. Define a quantidade de elementos do vetor como 5.
2. Solicita ao usuário cinco números inteiros.
3. Armazena os números em um vetor.
4. Inverte a ordem dos elementos utilizando uma variável auxiliar.
5. Exibe o vetor com os elementos invertidos.

## Conceitos utilizados

- Variáveis
- Vetores
- Estrutura de repetição for
- Entrada de dados com Scanner
- Manipulação de índices
- Troca de valores utilizando variável auxiliar
